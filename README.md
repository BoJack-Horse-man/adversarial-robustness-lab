# Adversarial Robustness Lab

A step-by-step learning and research project on adversarial robustness and efficient neural networks.

## Roadmap
1. Environment and GitHub setup
2. CIFAR-10/CIFAR-100 data pipeline
3. Clean ResNet-18 baseline
4. FGSM and PGD evaluation
5. Adversarial training
6. CIFAR-100 experiments
7. HYDRA code study and reproduction
8. Pruning comparison and research question

## Progress
See [PROGRESS.md](PROGRESS.md) for completed tasks, decisions, blockers, and next steps. See [PLAN.md](PLAN.md) for milestones and exit criteria.
